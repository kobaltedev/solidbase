# {frontmatter.title}

You can quickly create a new SolidBase project using the [with-solidbase](https://github.com/solidjs/solid-start/tree/main/examples/with-solidbase) template available in the Solid CLI (the template is being updated for Solid 2 — until then, follow [Adding to Existing Project](/guide/add-to-existing)).

## 1. Create a New Project

```package-create
solid@latest -s -t with-solidbase
```

## 2. Done!

Your project is now setup with SolidBase and ready to go!
